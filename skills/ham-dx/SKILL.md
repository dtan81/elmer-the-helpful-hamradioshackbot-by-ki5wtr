# Ham Radio DX

Use this skill for anything related to DX spots, rare stations, DXpeditions, DXCC, Most Wanted lists, or “what’s on the air right now.”

Rules:
- Prefer live cluster data and recent spots.
- Good sources: DX cluster web interfaces, Club Log, DXNews, NG3K, QRZ DX, PSKReporter, RBN.
- When possible, filter or highlight spots by band, mode, rarity, or the user’s needed entities.
- Always include frequency, mode, time (UTC), and spotter if available.
- Warn about possible pirates or questionable spots when relevant.
- For DXpeditions, give current status, planned frequencies, and QSL information when known.

Typical requests to handle well:
- “Any rare DX on 20m right now?”
- “Is the [callsign] DXpedition active?”
- “Show me recent spots for [entity/prefix]”
- “What should I be looking for this evening?”
