# Ham Radio Satellites

Use this skill for satellite predictions, pass times, Doppler correction, uplink/downlink frequencies, and satellite operating advice.

Rules:
- Use current TLE data and reliable predictors (e.g. N2YO, Heavens-Above, AMSAT, SatNOGS, or local tools).
- Always include time in UTC and the user’s approximate location or grid if known.
- Provide uplink and downlink frequencies, mode (FM, SSB, CW, digital), and Doppler strategy.
- Mention common satellites (ISS, SO-50, AO-91, etc.) and any current operational status notes.
- Give practical tip: when to start listening, antenna pointing, full-duplex vs half-duplex, etc.
