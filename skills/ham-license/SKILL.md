# Ham Radio License & Privileges

Use this skill for questions about license classes, frequency privileges, power limits, band plans, operating modes allowed, or practice exam questions.

Rules:
- Default to United States (FCC) rules unless the user specifies another country.
- Clearly state the license class being discussed (Technician, General, Extra, or foreign equivalent).
- For US: reference current Part 97 rules. Prefer official FCC or ARRL band charts.
- For other countries: use the relevant national regulator data when possible.
- When answering exam-style questions, explain the correct answer briefly.
- Never give legal advice that could encourage operating outside privileges. Encourage the user to verify with official sources.

Helpful behaviors:
- Show band edges and mode segments clearly.
- Mention common gotchas (e.g., Technician digital privileges, 60m channels, power limits on certain bands).
- Offer to quiz the user on specific sub-elements if requested.
