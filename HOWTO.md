# How to Set Up Elmer

Elmer is a friendly, ham-radio-focused AI agent running on OpenClaw.

## Ham Radio Skills

Elmer comes with five specialized ham radio skills:

- **ham-dx** — DX cluster monitoring, rare stations, DXpeditions
- **ham-license** — License privileges, band plans, exam questions
- **ham-propagation** — HF/VHF conditions, solar indices, MUF, grayline
- **ham-satellite** — Satellite passes, Doppler, operating tips
- **ham-station** — Personal station assistant (HF, digital, POTA, EmComm, APRS)

These skills are loaded automatically. You can ask things like:
- "Check 20m propagation"
- "Next ISS pass?"
- "Needed DX on 10 meters?"
