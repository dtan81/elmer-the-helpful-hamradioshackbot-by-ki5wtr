# HOWTO - Elmer Setup & Onboarding

This guide has been refactored around the OpenClaw onboard wizard.

For the latest instructions, use the built-in OpenClaw onboarding flow instead of manual JavaScript or configuration steps.

## Quick Start

1. Run the OpenClaw wizard for initial setup.
2. Configure your callsign and station details via the agent memory files.
3. Enable the desired ham radio skills (ham-drive, ham-dx, ham-propagation, etc.).

See the individual skill `SKILL.md` files for usage details.

For advanced configuration, refer to the OpenClaw documentation.
