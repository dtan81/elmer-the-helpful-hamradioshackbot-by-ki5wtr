# Contributing to Elmer

This is primarily a personal project maintained by KI5WTR.

## Reporting Issues
If you find an issue with the setup guide or documentation, feel free to open an issue. Please include:
- Which step you were following
- What went wrong
- Your environment (if relevant)

## Pull Requests
Pull requests are welcome, especially for:
- Clarifications in the setup guide
- Improvements to documentation
- Additional tips that helped you during replication

Please keep changes focused and include a clear description of what the PR addresses.
